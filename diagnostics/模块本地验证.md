# 侧键自定义 v0.5.0 本地验证

日期：2026-09-21。用户选择自行刷入，本次没有连接或操作手机。用户的设计截图与真机截图不进入仓库、源码包或安装包。

## 本次行为

- 窄侧栏宽度上限 196 dp，顶部两个开关，下方应用两列、整体内容可滚动；不再使用 8＋4 固定格子。深浅色跟随系统，保留 v0.4.4 全窗口遮罩修复。
- 应用通过批量勾选添加，名称／图标来自包管理器；应用不再提供手动名称或 emoji 输入。顶部两个开关仍可 DIY，旧版额外动作保留在 WebUI。
- 列表覆盖当前应用目录的 2048 项输入边界，配置空间 4 MiB，超过命令行长度的配置按 6000 字节分块；全部校验通过才写入 config.conf。中途失败不覆盖旧配置。
- 菜单不再把全部项目装进启动 Intent，而是通过一次性会话分页读取展示信息。应用行由 ListView 按需创建，图标缓存最多 128 项，WebUI 图标按可见项每批 16 个读取。
- 应用启动改为当前用户＋明确桌面组件＋桌面启动标志，并等待系统回执。明确拒绝小窗时尝试普通打开；超时／结果不明不重复启动。WebUI 增加应用启动日志。修正手势测试入口未传模块目录的问题。

## 验证结果

- ARM64 静态 ELF 与 16 KiB 段对齐、API 35 Java／资源编译、D8、APK v3 签名及版本 50 校验。
- 原有按键、手电筒状态、配置升级与严格字段校验，新增菜单 ITEMS 分页的令牌、过期、页边界及空列表校验。
- 2048 应用的 WebUI 序列化、C 解析、原子保存、重读与 JSON 往返；同一配置经十六进制分块解析结果一致。尾部重复字段和截断分块被拒绝且不覆盖旧配置。
- JavaScript 测试覆盖批量选择、自动名称、移除应用时保留旧开关、重复应用拒绝、PNG 图标边界和用户隔离、分块有序提交与失败清理，以及原有配置／桥接行为。
- 应用启动脚本使用系统命令替身检查当前用户、显式组件、管道描述符、小窗拒绝后的普通打开、错误文本不能算成功，以及超时不重复执行。安装脚本原有管道边界测试通过。
- 本地浏览器使用 12 个虚构应用及测试 PNG 进行交互检查，保存后重新读取有 12 个应用；搜索取消勾选后关闭弹窗，再打开仍为原先已选状态。测试数据与服务仅在忽略提交的 build 目录。
- 390×844 竖屏预览和 844×390 横屏检查双列；横屏滚动区可用高度 328 px、内容 710 px，滑到底部 scrollTop 为 382 px，后续应用可见。检查浅灰与深灰主题，深色背景计算为 rgba(48, 50, 55, 0.93)。

应用目录入口仍有既有过时 API 编译提示；菜单组件以 -Werror 编译通过。浏览器工具记录过一条未带工程源位置的 MutationObserver 错误，当前工程没有使用该 API；不以浏览器工具状态替代 Android 实机验证。
