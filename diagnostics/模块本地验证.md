# 侧键自定义 v0.5.3 本地验证

日期：2026-09-21。本次针对保存后手机菜单间距不变的反馈，并将快捷栏宽度下限调整为 120 dp。没有连接或操作目标手机。

## 修改与验证边界

v0.5.2 的配置字段能够保存，但原生菜单使用等分列宽和固定的上下留白；设置值与可见图标距离并不直接对应。用户反馈手机实际快捷栏没有变化。本次修正原生排布和参数传递，不将本地结果视为目标 ROM 的实机通过。

- 宽度、间距随当前菜单会话的分页数据一起下发。组件在创建界面前读取并校验，同一会话各页必须一致，不再从启动 Intent 单独读取这两个值。
- 原生应用行改为显式测量与定位。两个单元格最大各 64 dp，在栏内居中，间距直接参与坐标和行高计算；移除固定 10 dp 顶部及 8 dp 底部留白。
- 最后一行不添加行间距，奇数应用仍不补可见占位。
- 宽度范围统一为 120～360 dp：WebUI 滑块、配置校验、C 解析和原生测量均同步调整。
- 图标最大 44 dp；120 dp 窄栏搭配 32 dp 间距时自动缩小至 32 dp，避免越界。
- 菜单组件日志增加本次会话的宽度和间距，便于确认服务收到的保存值。
- 保留透明背景、只显示已配置项、两列滚动以及 ColorOS 仅小窗启动。

## 自动化检查

- 新增完整传递测试：WebUI 序列化 → C 解析 → 原子保存 → 原生菜单分页。覆盖宽度 120／196／360 和间距 0／12／32；验证两页参数一致、隐藏空项后索引正确、Shell 参数不进入界面数据。
- 新增原生排布几何测试，使用与实际 AppRow 相同的计算类。逐一检查 120～360 dp 宽度、七种 density 和五个间距值，验证图标与单元格边界。
- 在 196 dp 面板下，间距由 0 调到 32，两列中心距离和相邻行距离均增加完整 32 dp，末行没有附加留白。
- 120 dp 面板、32 dp 间距：两列单元格与图标均为 32 dp。瞬态极窄窗口不产生负尺寸或越界。
- 配置新下界 120 接受、119 拒绝，旧配置默认值保持 196／12；横竖屏和安全边距测试通过。
- 原有 C、Java、23 项 JavaScript 测试、2048 项分块配置、手电筒状态、OPlus 小窗状态确认、安装和启动脚本回归通过。
- ARM64 静态 ELF、16 KiB 对齐、API 35 编译、APK v3 签名与版本 53、DEX 和模块 ZIP 校验通过。

构建入口为 `python build.py`。应用目录仍有既有过时 API 编译提示；菜单 APK 使用 `-Werror` 编译。

## 浏览器界面检查

采用本地模拟配置与四个测试应用，不读取手机数据：

- 196 px 面板，间距 0：列中心距离 64 px，行距离 79 px。
- 196 px 面板，间距 32：列中心距离 96 px，行距离 111 px。两个方向均完整增加 32 px。
- 120 px 面板、间距 32：两列宽度与图标均为 32 px，全部位于面板内，外层背景透明。
- 390 × 844 竖屏切换为 844 × 390 横屏，120 px 宽度仍生效，面板处于窗口安全范围。

## 刷入确认

覆盖安装 v0.5.3 模块 ZIP 并重启，使监听服务和菜单组件一同更新。日志中的菜单组件版本应为 v0.5.3；每次打开会记录本次会话的宽度与间距。

原有动作与布局值会保留。在 WebUI → 你的快捷菜单中调整后保存；重新唤出快捷栏，比较间距 0 与 32 的效果。手机实际合成、触摸滚动、字体缩放和动画表现仍需要刷入确认。
