# 侧键自定义 v0.4.4 本地验证

日期：2026-09-21。用户选择自行刷入，本次没有连接或操作手机。

## 本轮顶部遮罩修复

- 用户截图中顶部未参与背景变暗。代码检查确认旧版将 WindowInsets 写入根容器 padding，而 ViewGroup 默认 clipToPadding=true，会裁掉该区域内的遮罩。
- MenuPanelHost 将安全边距单独保存并交给 MenuGeometry，只影响面板测量和定位；全窗口 shade 的测量、绘制范围不再使用根容器内边距。显式关闭 clipToPadding，避免重新引入边距裁剪。
- 主题保留透明状态栏、导航栏，显式启用系统栏背景绘制，并关闭 enforceStatusBarContrast / enforceNavigationBarContrast，避免额外对比度底色造成接缝；不隐藏状态栏或更改设备设置。
- 修改只涉及原生菜单容器、Insets 传递与主题。布局尺寸、动画时长、配置和按键动作保持不变；用户截图不进入仓库或交付。
- 验证范围：API 35 菜单 Java 使用 -Werror 编译、主题资源编译、APK 签名、原有几何边界测试及完整构建检查。电脑没有 Android 系统栏渲染环境，本次不将浏览器预览或几何测试当作实机遮罩验证。应用目录入口仍有既有过时 API 编译提示。
- 实机待验：原截图场景下顶部与中间背景亮度是否一致；旋转后顶部和侧面挖孔区域是否连续；菜单按钮是否继续避开系统栏；关闭后原应用恢复。

## v0.4.3 横屏修复

- 根据用户横屏截图修复原生面板最大宽度 720 dp 导致的拉伸，统一侧边面板宽度上限为 360 dp。截图本身不随源码或交付发布。
- 自定义容器在每次 Android 测量时重新读取窗口与安全边距，不再把前一次测量高度写回布局参数；标题固定，ScrollView 使用剩余高度，内容过长时可滚动至底部开关。
- 横屏或可用高度较小时采用紧凑卡片；大字体按实际行高增加卡片高度，允许滚动，不把字体强制缩放至不可读。
- 旋转和主题更新取消旧动画、重建布局但保留当前会话与显示状态；滑入、滑出距离包含当前安全边距。
- 新增 MenuGeometryTest，覆盖截图尺寸的多种密度、竖屏、正反横屏、左右面板、挖孔和导航边距、位置上下限、小窗口与异常瞬态尺寸。
- 本轮浏览器检查：844×390 横屏中面板宽 360 px，底部四个开关可见；打开状态切换到 390×844 竖屏重新定位且保留 12 个槽位；640×240 短窗口可滚动到底部，关闭按钮留在顶部。右侧弹出和深色配色完成检查，未出现控制台警告或错误。预览尺寸不等于 Android 原生测量或真机动画验证。
- 本轮 APK 已通过 API 35 编译和签名校验，新增几何边界测试及原有 C、Java、18 项 JavaScript 和安装脚本测试均通过。应用目录入口仍有既有的过时 API 编译提示，原生菜单 Java 使用 `-Werror` 编译通过。
- 尚需手机检查：横屏视频/游戏中从左右边缘打开、打开后正反旋转、下方开关点击、大字体滚动、关闭再打开；本次不连接手机，不宣称这些实机行为已经验证。

## 此前新增行为

- v0.4.2：通过 Root app_process 查询当前 Android 用户的 MAIN / LAUNCHER 入口，按包名去重并读取显示名称。WebUI 统一应用选择弹窗，支持名称或包名搜索、刷新、读取失败重试；最多缓存 10 秒，列表不写盘。普通启动、小窗和菜单卡片都不再要求手动填写包名；手动卡片名称保留。
- 根据实机反馈的 `Failed transaction (2147483646)`，修正启动命令 stdout / stderr 直接指向私有日志文件的路径；父进程从管道非阻塞收集输出，日志限制 64 KiB 加一条结果说明。安装脚本也通过管道传递日志与 APK，保留失败退出码。
- 打开菜单等待命令成功和组件 PING 握手，8 秒截止；创建子进程不再被当作菜单启动成功。日志区分命令是否结束、组件是否握手。

- 增加“弹出快捷菜单”动作，可绑定短按、双击或长按。默认显示 8 个 APP 和 4 个开关占位、左侧滑出、中心高度 35%；可选右侧和 10%～90% 高度。
- 布局按用户指定设计图：上方 2×4 应用卡片，下方 4 个快捷开关；名称、emoji、动作、参数、位置和同组排序在 WebUI 配置。未配置槽位保持占位，不包含预设应用和动作。
- 原生 Activity 读取系统 uiMode；系统主题或屏幕配置变化时重新应用配色和位置。WebUI 预览采用 prefers-color-scheme。
- 新增 app_freeform 动作，请求 Android windowingMode=5；是否按小窗启动仍需 ColorOS 与应用支持，不修改开发者选项。
- 手电筒开关使用当前手电筒服务 PID 匹配后的 known / available / enabled 状态，PING 心跳约 2 秒更新；未知状态显示横线，单次动作显示执行符号。
- 透明 Android Activity 负责呈现，进入约 280 ms、退出约 180 ms；点击空白处、返回键或超时关闭。选择项目在 Activity 停止后提交，减少菜单覆盖截屏或拦截返回键的机会。
- 小型菜单 APK 随模块分发，开机后自动通过包管理器准备。WebUI 可重试；安装、启动错误进入菜单日志。
- 只监听 127.0.0.1 随机端口，Root 私有打开令牌和 256 位一次性点击会话分离；客户端只提交索引，不传 Shell 或其他动作参数。限制连接数量、长度、等待时间，60 秒后失效；配置重载使旧菜单失效。
- 保留独占接管、动作队列、震动和系统手电筒；菜单中配置手电筒也会准备原有 CameraManager 服务。

## 已完成的本地检查

- ARM64 静态 ELF 编译，`-Wall -Wextra -Werror`，无动态解释器、16 KB 段对齐。
- 原有 9 类手势测试；旧配置升级为空菜单、位置和数量边界、重复字段、缺失字段、菜单递归与非法动作拒绝；补充固定槽位范围、重复槽位和小窗动作参数校验。
- 菜单协议测试：令牌错误、空令牌、超时、索引越界、负值、注入字符、尾部多余字符均拒绝；PING、CLOSE 和合法选择通过。
- 18 项 JavaScript 测试通过，除原有配置和桥接测试外，覆盖应用搜索、去重、同名不同包、非法列表、Unicode 名称截断、保留手动名称、缓存过期、并发读取和错误重试。
- 新增 C 启动结果测试：只有 am 完成和组件握手同时满足才成功，覆盖任意顺序、失败状态与截止边界；原有手势和菜单协议测试仍通过。
- 新增 Java 应用目录模型测试：去重、非法包名拒绝、名称回退、控制字符、emoji 完整性与 2048 项边界。应用读取入口已通过 Android API 35 编译，系统隐藏接口的 ColorOS 可用性仍待手机验证。
- 安装脚本在 Git Bash 中使用包管理器替身验证：stdin APK 和 stdout / stderr 均为管道、安装错误不写成功标记；将重定向改回私有文件时，测试成功捕捉失败。该测试模拟文件描述符约束，不替代 Android SELinux 实测。
- WebUI 序列化 → C 解析 → 原子写入 → 重新读取 → JSON 往返，覆盖中文名称、emoji、菜单动作、槽位 3 和 10、小窗动作、关闭震动与多行 Shell。
- 原有 10 类 Java 手电筒逻辑场景通过：最高亮度、重复切换、外部同步、占用、初始化及回调超时、不重试、API 失败、单档默认亮度和异步确认。
- 菜单 Java 使用 API 35 编译，D8 采用该工具支持的 API 34 字节码下限；APK Manifest 的安装下限和目标均为 API 35。APK 包名、版本、DEX 完整性和 v3 签名通过校验。APK 不含原生库。
- 390×844 本地浏览器实点：8＋4 占位、应用默认小窗动作、保留空位、开关独立配置和预览。通过浏览器模拟系统颜色偏好，已检查深灰和白色配色实时切换，布局不变、无横向溢出。原有添加、名称与 emoji、参数、排序、左右预览和删除也完成实点。无控制台错误或警告。预览不能代表 Android 原生动画实测。
- Shell / JavaScript 语法、UTF-8 无 BOM / LF、模块 ZIP 根目录、权限标记与文件内容校验。

## 本轮设备反馈

用户提供的日志确认短按、双击已识别且进入菜单动作；菜单启动返回 Android activity 服务 Binder 事务错误。旧版动作同时返回 0 是提前确认造成的结果报告缺陷。仅凭日志不能证明 SELinux 拒绝的具体规则，文件描述符问题是结合代码作出的定位，未获取新的设备审计日志。手电筒服务日志报告相机 0、最高 4 档及开启/关闭成功；不据此宣称控制中心图标或实际亮度已验证。

5. 检查返回键、点击外部、连续触发、60 秒超时、配置修改、暂停接管和服务停止后的关闭行为。
