# 侧键自定义 v0.2.0 本地验证

日期：2026-09-16。目标设备由用户自行安装，未继续执行手机端操作。

## 已验证

- ARM64 静态 ELF 编译，启用 `-Wall -Wextra -Werror`；无动态解释器，加载段按 16 KB 对齐。
- C 原生测试：直接短按、延迟短按、双击、长按只触发一次、重复／孤立事件、双击时间边界、第二次按压变成长按、大时间戳、配置重置取消待执行手势。
- C 配置校验：必填字段、重复字段、阈值范围、十六进制非法字符、嵌入空字节与长度上限。
- JavaScript 测试：默认配置、中文／引号／换行序列化、非法参数、Shell 参数引用、应用包名。
- 使用模拟 KernelSU 回调验证 WebUI 桥接的成功返回、错误返回、非法 JSON、超时和回调清理；这不代表手机管理器桥接已经验证。
- 前后端往返：WebUI 序列化的配置交给实际 C 解析器，返回 JSON 后核对中文、引号和换行。
- Shell 语法检查、JavaScript 语法检查、模块文本编码与换行检查。
- ZIP 根目录、文件权限标志、完整性与文件内容一致性检查。
- 本地浏览器 390×844 移动端预览：页面加载、三种手势选择、应用包名与 Shell 输入切换、未保存状态、预览模式阻止手机写入。

真实编译命令、测试结果和包校验结果保存在每次交付目录的 `构建日志.txt`。

## 实机验证边界

之前已经从手机实际读取侧键事件，确认 `gpio-keys`、Linux 键码 735（0x02DF）、按下 1／松开 0；原始证据见同目录记录。

本版新增模块尚未在手机验证：

1. EVIOCGRAB 是否被当前 KernelSU／SELinux 环境允许，及原系统动作是否完全被阻断。
2. 管理器 WebUI 桥接、安装和开机启动流程。
3. 各种系统动作、锁屏状态、息屏时手势响应、系统应用启动限制。
4. 暂停、禁用、升级与卸载在手机上的完整流程。

本地自动化不能替代这些实机检查。安装后可先选择“展开通知栏”作为短按动作，保存启用，再观察状态是否为“侧键已接管”及日志是否出现单击。
