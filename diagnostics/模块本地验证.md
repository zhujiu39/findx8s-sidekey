# 侧键自定义 v1.0.0 本地验证

日期：2026-09-21。构建入口：`python build.py`。

## 发布范围

基于 v0.5.3 整理首个正式版。此次调整集中在界面文案、维护工具位置、安装提示、版本信息和发布文档，去掉逐次菜单布局调试输出。手势识别、配置格式、应用布局和 ColorOS 小窗执行方式保持原有实现。

模块、菜单 APK、WebUI 与构建版本统一为 v1.0.0；模块及 APK 的 versionCode 为 100，沿用原 APK 签名，支持覆盖升级。

## 构建与自动化检查

完整构建包含以下检查，实际命令结果记录在本次交付目录的 `构建日志.txt`：

- C：手势状态机、配置解析、旧配置兼容、菜单协议和启动状态。
- Java：手电筒状态、应用目录、ColorOS 小窗确认、菜单安全区域与双列布局。
- JavaScript：WebUI 配置、应用勾选、图标加载和配置上传。
- 跨语言配置往返、2048 项配置分块、宽度与间距随菜单分页传递。
- 安装及启动脚本的管道边界、失败退出码和 Shell 语法。
- ARM64 静态 ELF、16 KiB 段对齐、API 35 编译、DEX、APK 签名与版本、模块 ZIP 内容及权限。

应用目录编译保留既有过时 API 提示；菜单 APK 使用 `-Werror` 编译。

## 界面与发布检查

- 主设置页使用简洁文案，“修复快捷菜单”位于默认收起的“运行状态与日志”内。
- 原有保存、手势执行、应用选择、外观预览和日志入口保留。
- 版本统一，安装包使用 `release_` 前缀；GitHub Release 为正式发布。
- 安装包只包含运行文件与许可证，不含源码测试、模拟数据、构建日志、签名私钥或个人文件。
- 发布附件提供 SHA256 校验文件；公开下载后比对内容。

## 验证边界

本次执行本地构建、自动检查与浏览器界面检查，没有连接目标手机，不新增实机通过结论。此前用户已反馈 ColorOS 小窗版本可用；不同 ROM、应用支持情况及手机上的具体动画、触摸效果仍受设备环境影响。

覆盖安装正式版后需重启，让监听服务与菜单 APK 一同更新。已有配置保留。
