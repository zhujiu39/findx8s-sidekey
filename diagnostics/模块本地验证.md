# 侧键自定义 v0.4.1 本地验证

日期：2026-09-21。用户选择自行刷入，本次没有连接或操作手机。

## 新增行为

- 增加“弹出快捷菜单”动作，可绑定短按、双击或长按。默认显示 8 个 APP 和 4 个开关占位、左侧滑出、中心高度 35%；可选右侧和 10%～90% 高度。
- 布局按用户指定设计图：上方 2×4 应用卡片，下方 4 个快捷开关；名称、emoji、动作、参数、位置和同组排序在 WebUI 配置。未配置槽位保持占位，不包含预设应用和动作。
- 原生 Activity 读取系统 uiMode；系统主题或屏幕配置变化时重新应用配色和位置。WebUI 预览采用 prefers-color-scheme。
- 新增 app_freeform 动作，请求 Android windowingMode=5；是否按小窗启动仍需 ColorOS 与应用支持，不修改开发者选项。
- 手电筒开关使用当前手电筒服务 PID 匹配后的 known / available / enabled 状态，PING 心跳约 2 秒更新；未知状态显示横线，单次动作显示执行符号。
- 透明 Android Activity 负责呈现，进入约 280 ms、退出约 180 ms；点击空白处、返回键或超时关闭。选择项目在 Activity 停止后提交，减少菜单覆盖截屏或拦截返回键的机会。
- 小型菜单 APK 随模块分发，开机后自动通过包管理器准备。WebUI 可重试；安装、启动错误进入菜单日志。
- 只监听 127.0.0.1 随机端口，Root 私有打开令牌和 256 位一次性点击会话分离；客户端只提交索引，不传 Shell 或其他动作参数。限制连接数量、长度、等待时间，60 秒后失效；配置重载使旧菜单失效。
- 保留独占接管、动作队列、震动和系统手电筒；菜单中配置手电筒也会准备原有 CameraManager 服务。

## 已完成的本地检查

- ARM64 静态 ELF 编译，`-Wall -Wextra -Werror`，无动态解释器、16 KB 段对齐。
- 原有 9 类手势测试；旧配置升级为空菜单、位置和数量边界、重复字段、缺失字段、菜单递归与非法动作拒绝；补充固定槽位范围、重复槽位和小窗动作参数校验。
- 菜单协议测试：令牌错误、空令牌、超时、索引越界、负值、注入字符、尾部多余字符均拒绝；PING、CLOSE 和合法选择通过。
- 13 项 JavaScript 测试通过，涵盖默认值、中文和 emoji、最长配置、非法菜单、原有动作和 KernelSU 回调模拟。
- WebUI 序列化 → C 解析 → 原子写入 → 重新读取 → JSON 往返，覆盖中文名称、emoji、菜单动作、槽位 3 和 10、小窗动作、关闭震动与多行 Shell。
- 原有 10 类 Java 手电筒逻辑场景通过：最高亮度、重复切换、外部同步、占用、初始化及回调超时、不重试、API 失败、单档默认亮度和异步确认。
- 菜单 Java 使用 API 35 编译，D8 采用该工具支持的 API 34 字节码下限；APK Manifest 的安装下限和目标均为 API 35。APK 包名、版本、DEX 完整性和 v3 签名通过校验。APK 不含原生库。
- 390×844 本地浏览器实点：8＋4 占位、应用默认小窗动作、保留空位、开关独立配置和预览。通过浏览器模拟系统颜色偏好，已检查深灰和白色配色实时切换，布局不变、无横向溢出。原有添加、名称与 emoji、参数、排序、左右预览和删除也完成实点。无控制台错误或警告。预览不能代表 Android 原生动画实测。
- Shell / JavaScript 语法、UTF-8 无 BOM / LF、模块 ZIP 根目录、权限标记与文件内容校验。

每次交付中的“构建日志.txt”来自该次真实构建。菜单 APK 签名私钥只在忽略提交的 tools/private 中保留，不进入模块、源码或 Release。
