# OPPO Find X8s 侧键适配

适配对象：OPPO Find X8s（PKT110），Android 15 / ColorOS 15。

| 项目 | 值 |
| --- | --- |
| 输入设备 | `gpio-keys` |
| 事件类型 | `EV_KEY`（1） |
| Linux 键码 | `735` / `0x02DF` / `BTN_TRIGGER_HAPPY32` |
| 按下 / 松开 | `1` / `0` |
| 设备路径特征 | `odm:oplus_magic_key` |

监听器动态查找设备，不固定 `/dev/input/event0`。只有确认设备没有承载其他按键后才通过 `EVIOCGRAB` 独占；进程退出后释放。

长按根据按下时间判断，不依赖内核重复事件。配置变化时会清除当前手势，避免把已按住的键识别为新动作。

735 是 Linux 输入键码，不是 `input keyevent` 使用的 Android KeyEvent 编码。
