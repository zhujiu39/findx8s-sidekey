<a id="compatibility"></a>

## 📱 适用环境

- **手机：** OPPO Find X8s。
- **系统：** Android 15 / ColorOS 15，ARM64。
- **Root：** 已安装并正常工作的原版 KernelSU，可打开模块 WebUI。

其他机型、ROM 和 Root 方案不在当前适配范围内。安装本模块无需重新修补 `boot` / `init_boot`，不依赖 Zygisk 或元模块。

<a id="quick-start"></a>

## ⚡ 快速开始

1. 在 **KernelSU → 模块 → 从本地安装** 中选择模块 ZIP，安装完成后重启。
2. 从模块卡片打开 **WebUI → 手势**，点击短按、双击、长按对应的行，展开并选择动作。
3. 按需开启触发震动，在 **设置** 页调节长按时间和双击间隔。
4. 开启 **接管侧边键**，点击 **保存设置**。

首次安装默认暂停接管，所有手势均为“不执行动作”。保存后展开对应手势，点击 **执行** 按钮可直接运行该动作。

开启接管会替换侧键原有功能；关闭接管并保存，即可恢复系统处理。

### 设置快捷菜单

1. 将任意手势设为 **弹出快捷菜单**。
2. 在 **快捷栏 → 勾选应用** 中选择常用应用，点击 **使用所选应用**。
3. 按需添加快捷开关，选择开关动作；使用箭头调整顺序。
4. 调整外观，点击 **保存设置**，解锁后通过侧键打开。

开关排列在上方，应用按两列排列，内容超出面板时可上下滑动。未设置动作的开关不显示；未选择应用时不显示应用区；全部留空时不弹出面板。

| 设置 | 默认值 | 范围 |
| --- | --- | --- |
| 快捷栏宽度 | 196 dp | 120～360 dp |
| 应用间距 | 12 dp | 0～32 dp |
| 面板中心高度 | 35% | 10%～90% |
| 弹出方向 | 左侧 | 左侧 / 右侧 |

应用名称与图标跟随手机。菜单应用统一以 **ColorOS 小窗** 打开；系统或应用不支持时会报告失败，不会改为全屏。点击应用后菜单收起；点击快捷开关后菜单保持打开，可继续操作。点击面板外、顶部短横线或返回键可收起菜单。

### 设置手电筒

将任意手势或快捷开关设为 **切换手电筒（系统最高亮度）**，保存后即可使用。通过控制中心改变灯光后，侧键会按当前系统状态继续切换。

亮度取系统公开的最高档位，受温控、相机占用及 ROM 限制。快捷菜单中的手电筒开关会显示实际状态。

### 切换 WebUI 样式

进入 **设置 → 界面样式**，选择 **墨白极简** 或 **石墨工具箱**。默认使用墨白极简，切换立即生效，重新打开后保留选择。两套样式的深浅色都跟随系统。

样式仅影响 WebUI 设置页面，侧键唤出的快捷菜单保持原有外观。切换样式不会清空未保存的配置；手势、应用和布局修改仍需点击 **保存设置**。

### 连接米家（v1.1.0-test.6）

1. 打开 **米家 → 登录米家 → 生成登录二维码**，使用米家 App 扫一扫授权。本机可截图，再从扫一扫的相册中识别。
2. 选择家庭，在房间分组中点击设备，选择系统规格支持的开关、亮度、模式等动作；也可以选择米家手动场景。
3. 点击 **加入快捷菜单**，再点击底部 **保存设置**。实际设备控制从侧键弹出的快捷菜单完成。
4. 执行结果在米家页的 **最近执行结果** 查看。“已受理”表示云端或网关已接收；只有读回状态吻合才显示“已确认”。请求中断不会自动重发。

快捷栏中的米家开关会在**展开时和每次米家操作完成后**读取实际的布尔属性：开是绿色电源图标，关是灰色电源图标；执行期间显示“执行并刷新中”。操作后的首次读回若仍是旧值，会短暂复查刚操作的属性，确认一致后才更新图标；首次一致则立即完成。读回失败或有限次复查仍无法确认时显示未知，不把旧的相反状态当作最终结果。空闲时不会定时向米家查询。场景执行后也会刷新快捷栏中的设备开关状态；场景、设备动作和没有可读布尔属性的绑定仍显示普通执行符号。点击米家动作后菜单保持打开，结果返回后可继续操作。

如遇状态异常或响应慢，进入 **设置 → 运行状态与日志 → 导出完整日志**。系统会弹出“另存为”，可以选择保存位置并修改文件名，默认文件名为 `findx8s-sidekey_年月日_时分秒.log`。保存后直接发送这个文件即可，避免粘贴长文本被截断。

完整文件包含版本、时间、所有日志分类及手机上仍保留的上一段日志，**不再按每个文件 64 KiB 截取**。米家日志包含请求编号片段、目标开关状态、每次读回值、返回码和耗时；不读取登录凭据、二维码或设备缓存。传输校验和文件写入完成后才提示成功，取消文件选择不生成日志文件。总日志异常超过 64 MiB 时会明确报错，不生成伪装完整的截取文件。

原来的 **复制全部日志** 仍可使用，单文件超过 64 KiB 会注明截取；完整排查优先使用文件导出。自动复制受限时会显示文本框，可长按全选复制。

当前面向中国大陆账号和支持 MIOT 的设备。不支持 MIOT 的旧设备可在米家 App 创建手动场景使用。无需另装 Python 或 Termux；普通侧键动作仍离线可用。快捷菜单的布局和应用小窗路径保持原有实现。

凭据只存放在手机 `/data/adb/oppo_sidekey/mijia/` 私有目录，WebUI 不显示令牌。**退出并清除登录**会删除凭据及米家动作，原有米家绑定需重新配置。服务来源、许可和接口边界见 [米家服务说明](mijia/README.md)。本地测试和匿名扫码握手已验证，真实手机账号及设备控制仍需测试反馈。

### 从旧版升级

在 KernelSU 中覆盖安装并 **重启手机**。已有手势、菜单项目、宽度、间距和其他设置会保留，无需卸载模块。

## 🎛️ 支持的动作

| 类别 | 动作 |
| --- | --- |
| 快捷菜单 | 弹出侧边快捷菜单 |
| 系统导航 | 回到桌面、返回、最近任务 |
| 快捷操作 | 通知栏、快捷设置、截屏、息屏 |
| 媒体控制 | 播放 / 暂停、上一首、下一首、音量增减、媒体静音 |
| 相机与灯光 | 打开相机、切换手电筒 |
| 应用 | 普通启动、ColorOS 小窗启动；从应用列表选择 |
| 自定义 | Android 按键码、Shell 命令 |
| 留空 | 不执行动作 |

菜单中的应用始终使用小窗；手势直接绑定应用时，可以选择普通启动或小窗启动。

Shell 以 Root 身份执行，单次最长 **10 秒**，命令最多 **512 个 UTF-8 字节**。动作结束会清理其后台子进程，不适合运行常驻脚本。Android 按键动作接受 `1～2047` 的 KeyEvent 编码。

## 🤏 手感调节

| 设置 | 默认值 | 范围 |
| --- | --- | --- |
| 长按触发时间 | 600 ms | 250～2000 ms |
| 双击最大间隔 | 280 ms | 150～600 ms |
| 触发时震动 | 开启 | 开启 / 关闭 |

启用双击动作后，短按需要等待双击间隔结束。长按达到阈值时执行一次，继续按住或松手不会重复执行。

震动表示动作已触发；实际执行结果可在运行日志中查看。

## ❓ 常见问题

<details>
<summary><strong>安装后按键没有变化？</strong></summary>

请先配置动作，再开启“接管侧边键”并保存。如果状态显示“监听服务未启动”，可在“运行状态与日志”中点击“启动监听服务”。升级后需要重启。

</details>

<details>
<summary><strong>快捷菜单无法打开，需要悬浮窗权限吗？</strong></summary>

无需悬浮窗、无障碍或单独 Root 授权。确认手机已解锁、菜单内有已配置项目，然后在“运行状态与日志”中点击“修复快捷菜单”，并查看“菜单组件”日志。

</details>

<details>
<summary><strong>应用无法以小窗打开？</strong></summary>

小窗依赖 ColorOS 和应用自身支持。请查看“运行状态与日志 → 应用启动”中的错误原因，反馈时附上应用名称和系统版本。

</details>

<details>
<summary><strong>手电筒不够亮、状态异常或无法开启？</strong></summary>

确认使用的是内置“切换手电筒”动作。亮度上限由系统决定；相机占用、温控或系统限制可能阻止开启。运行状态中可查看实际亮度、可用状态和错误原因。

</details>

<details>
<summary><strong>怎样恢复原功能或卸载？</strong></summary>

关闭“接管侧边键”并保存即可恢复原功能，也可以在 KernelSU 中禁用模块并重启。卸载会删除模块配置，并移除“侧键快捷菜单”组件。

</details>
