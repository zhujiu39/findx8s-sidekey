# 侧键自定义 · Apple 风格交互预览

基线为 `C:\Users\14692\.codex\worktrees\findx8s-sidekey-publish\anjian`，`main` 分支的 `4697ac9e4e212b345b9007dab25af55233b720c5`，`module/module.prop` 为 **v1.2.0-test.2 / versionCode 115**。桌面旧目录的 v0.3.1 预览不再作为本次设计依据。

这是独立浏览器预览。账号、应用清单、设备状态、米家读数、Surfing 用量及日志均为明确标注的示例数据。预览设置只写入专用 localStorage，页面不访问手机、不执行 Root 命令，也不访问米家或 Surfing 接口。

## 设计取向

- 桌面采用左侧导航、中心编辑区和右侧实时快捷栏；窄屏采用底部四页导航。
- 手势页仅保留接管、三种按法、快捷栏摘要和触感反馈。点击手势展开编辑，再从分组面板选择动作。
- 快捷栏先展示简洁的项目列表，点开后再编辑名称、动作、文案。排序与移除保留；布局调节集中呈现。
- 米家按家庭、场景、房间和已配置项目组织。详情保留读数、控制与设定，当前温度与目标温度分开。
- 主页面使用实色分组，只有浮动保存区、弹出菜单和导航使用半透明材质。强调色用于操作和当前选择，状态同时有文字。
- 入场动画约 250～300 ms，点击反馈约 180 ms。遵循 `prefers-reduced-motion`，另有预览内“减少动态效果”设置。
- 深色、浅色及跟随系统即时生效，外观偏好与业务配置分别保存。
- 所有界面符号均提取自用户提供的 SF Symbols 文件。用户库未提供某些填充变体时，使用库中同一符号的单色轮廓或明确记录的同义符号，没有重绘图标路径。

设计参考：[Apple HIG 入门](https://developer.apple.com/cn/design/human-interface-guidelines/getting-started)、[布局](https://developer.apple.com/design/human-interface-guidelines/layout)、[动效](https://developer.apple.com/design/human-interface-guidelines/motion)、[SF Symbols](https://developer.apple.com/sf-symbols/)。这是参照 Apple 设计原则的网页实现，不是 UIKit 或 SwiftUI 原生界面。

## 预览操作

1. 首页点击“短按 / 双击 / 长按”更换动作。修改后点击底部“保存设置”，再点击“体验”。
2. 在快捷栏点开 Surfing，修改五项显示开关和八项文案。右侧桌面预览同步更新；窄屏点击“打开预览”。
3. 米家页选择温湿度传感器，可组合 1～4 项只读数据；选择空调，可分别查看当前温度、目标温度、模式及参数动作。
4. 打开侧边菜单，点击灯、手电筒或 Surfing；点击应用可查看小窗示意。关闭按钮、外部点击及 Escape 均可退出。
5. 顶部“示例状态”切换设备离线、状态未知、Surfing 未安装、订阅未提供、订阅读取失败、多个订阅等。
6. 顶部预览选项可恢复示例配置，或切换为空白的首次安装状态。恢复操作只清理此预览自身的数据。
