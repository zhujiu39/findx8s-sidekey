# v1.2.0-test.10 · 卡片颜色与紧凑读数

2026-09-28，版本码 123。本地实测包。

## 本次修改

根据用户截图及随后确认，修改双击侧键弹出的原生快捷菜单：

1. 删除蓝框中的“云端上报”，正常只读卡片直接显示标题和读数，不保留该行空白；离线或状态未确认时仍显示最近上报提示。
2. 红框中的每项名称和数值放在同一行，温度与湿度仍是两行，例如“温度 24.5°C”“湿度 73%”。示例数字不进入产品，实际数据仍由米家提供。
3. 名称 12 sp、数值 14 sp，收紧上下留白，摄氏度、华氏度和百分号紧随数值。自定义文案留空时只显示数值，长文案自然换行，数值、单位与原始无障碍文本保留。
4. 取消右侧独立开关按钮，点击整张卡片继续执行原动作。真实状态为开启时绿色、关闭时中性灰；切换中为蓝色附刷新标记，未知或离线为琥珀色附异常标记，不冒充关闭。普通执行动作与只读卡片保持中性。
5. 快捷菜单标题最大字号由 13 sp 降为 12 sp，并根据可用宽度在 10～12 sp 适配。取消右侧按钮后，普通字体下最窄 120 dp 栏宽可完整容纳五个中文字符；更长名称仍按空间省略。
6. 整张卡片保留至少 48 dp 的触控高度、按压反馈、禁用规则与无障碍状态说明；WebUI 布局预览同步卡片颜色和无按钮布局。预览不读取的开关按未知显示，Surfing 点击只切换开启后的布局示意。

保留 test.9 的应用图标读取及复制诊断、Surfing 仅开启时显示详情、深浅色、米家后台、手势、配置格式与 APK 签名。

## 安装与实测

在 KernelSU 覆盖安装 `test_oppo_sidekey_v1.2.0-test.10.zip` 并重启。重新打开 WebUI，确认版本 test.10，再双击侧键查看实际菜单。

- 温湿度计正常有数据时，不再显示“云端上报”；“温度 数值”“湿度 数值”各占一行。
- 使用五字中文卡片标题，检查当前窄栏下能否完整显示；更长名称允许省略。
- 检查自定义空文案、长文案、无数据与离线状态，数值和单位不能被遮挡。
- 确认右侧独立按钮消失，点击整卡可操作手电筒、米家与 Surfing；真实结果返回后卡片变为开启／关闭色，切换中与未知不会显示为已关闭，只读卡片不能操作。
- 检查深浅色、左右展开、整卡触控和滚动。系统大字体或特殊长读数可能换行，以保持可读。
