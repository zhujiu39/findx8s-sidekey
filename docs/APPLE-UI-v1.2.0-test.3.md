# v1.2.0-test.3 · Apple 风格界面与原生快捷栏

基于指定工作树的 v1.2.0-test.2（版本码 115），接入已确认的 Apple 风格设计。本版版本码 116，为本地实测包。

## 安装

在 KernelSU → 模块 → 从本地安装中选择 `test_oppo_sidekey_v1.2.0-test.3.zip`，覆盖安装后重启。保留 `/data/adb/oppo_sidekey` 下的既有配置与账号数据，使用原有菜单组件签名。无需单独安装 APK、米家服务或源码包。

首次打开 WebUI 可看到“手势、快捷栏、米家、设置”四页。修改模块选项后点击底部“保存设置”；界面外观和 WebUI 减少动态效果即时生效。

## 本版变化

- WebUI：四页导航、大标题、分组列表、折叠编辑、分组动作选择、底部保存状态、原生对话框与按压反馈。
- 图标：导航、动作、控制与占位图标使用用户提供的 SF Symbols。同一图形路径用于网页 SVG 与 Android 矢量图标。应用身份图标继续取自手机，便于识别。
- 外观：WebUI 提供浅色、深色、跟随系统；原生菜单深浅色跟随 Android 系统。手机侧使用系统字体，按层级重排字号、行距和留白。
- 动效：WebUI 使用短过渡、底部弹层与菜单滑入／收起，可开启减少动态效果；原生菜单增加按压反馈，跟随系统动画开关。
- 真机菜单：独立只读数据区域；开关展示真实开启、关闭、离线、未知、操作中状态；窄面板改用更易读的纵向排列。应用保持双列小窗入口。
- Surfing：保留全部四项统计、订阅用量、显示勾选与八项文案；有效订阅用量增加进度显示，多个套餐分别列出，缺失用量或总额明确提示。
- WebUI 的“布局预览”展示当前草稿，状态和数据用占位表示；按侧键进入实际菜单，才能读取状态和控制设备。

## 真机实测顺序

1. 覆盖安装并重启，确认版本为 v1.2.0-test.3、原手势和快捷栏项目仍在。进入四页，修改一项配置并保存，重新打开确认。
2. 分别试短按、双击、长按；检查震动和对应动作。保存前“执行”不可用，保存后按已配置动作执行。
3. 按侧键打开菜单：检查当前宽度、左右方向、横竖屏和上下滚动；再试较窄宽度。点开关保持菜单展开，点应用收起菜单并进入小窗。
4. 米家：确认家庭、设备、场景与已配绑定；试设备开关和只读卡片，核对真实设备、数值、文案、在线／离线状态及执行结果。
5. Surfing：启停、四项统计、勾选隐藏、空文案、订阅已用／总额；确认没有订阅元数据时明确显示缺失提示。
6. 切换系统深浅色，检查原生菜单；分别选择 WebUI 的浅色、深色、跟随系统和减少动态效果。
7. 在设置页复制日志、导出完整日志，确认系统保存和取消路径正常。
