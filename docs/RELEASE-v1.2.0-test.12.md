# v1.2.0-test.12 · 参考图圆角与指定配色

2026-09-28，版本码 125。本地实测包。

## 本次修改

按用户提供的卡片形状、绿色色块及蓝色色值修改。用户已明确：只参考卡片形状，继续整卡点击，不恢复右侧圆形按钮。

- 卡片保留实心白底、16 dp 圆角和至少 48 dp 高度，窄栏左右 8 dp 留白；外层使用参考图浅灰 `#F6F6F6`，移除 test.11 的卡片描边和投影。
- 开启绿色逐像素取自用户色块，为 `#0DCD94`；等待蓝色严格采用 `#66CCFF`；未知或离线使用柔和蜜黄 `#F4C66A`。
- 状态色在深浅两套主题使用同一色值；关闭、普通动作、只读卡片在深色模式仍采用深灰背景，外层保持深色。
- 标题、状态标记及 Surfing 文案、读数、进度条使用配套深色前景；WebUI 布局预览同步形状、底色和配色。

保留五字标题空间、温湿度名称和数值同行、正常数据不显示“云端上报”、整卡点击、原有状态判断和禁用条件、图标获取与诊断。无配置格式或签名变化。

## 安装与实测

KernelSU 覆盖安装 `test_oppo_sidekey_v1.2.0-test.12.zip` 并重启，重新打开 WebUI 确认版本 test.12，再双击侧键查看。

1. 对照参考图检查白色圆润卡片与浅灰外层，确认右侧圆形按钮未恢复。
2. 检查开启为图样绿色、等待为浅蓝、未知或离线为蜜黄；读数卡片不显示为开关。
3. 检查 Surfing 开启后的数字与说明、温湿度两行、五字标题及滚动后的卡片复用。
4. 切到深色模式，普通背景应变深，状态色保持指定色值，文字应清晰。
