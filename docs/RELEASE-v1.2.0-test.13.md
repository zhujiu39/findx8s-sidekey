# v1.2.0-test.13 · 去除顶部占位与标题居中

2026-09-28，版本码 126。本地实测包。

## 本次修改

依据用户截图中的红框和蓝框调整原生快捷菜单。

1. 删除红框内顶部横条及其 44 dp 整块占位。菜单顶部仅保留与左右相同的 10 dp 正常边距，保留圆角外框；点击菜单外及系统返回仍可收起。
2. 蓝框中的卡片标题改为水平居中，快捷操作、米家、只读卡片和 Surfing 同步；辅助状态提示也居中。
3. 显示等待、异常或类型图标时使用左右对称占位，标题仍相对卡片居中。最窄栏保留普通字体五字标题空间。
4. WebUI 布局预览同步移除顶部横条、居中标题。已有页面预览入口与关闭按钮保留。

整卡点击、圆角底色、图样绿 `#0DCD94`、指定蓝 `#66CCFF`、蜜黄 `#F4C66A`、温湿度名称与数值同行均沿用 test.12；状态判断、命令、图标和配置格式不变。

## 安装与实测

KernelSU 覆盖安装 `test_oppo_sidekey_v1.2.0-test.13.zip` 并重启，重新打开 WebUI 确认 test.13，再双击侧键查看。

- 顶部横条和大块空白消失，第一张卡片与外框保持正常间距。
- 五字标题在卡片中间，普通状态和等待／异常状态都不偏向一侧。
- 温湿度标题居中，读数仍按原两行方式显示；应用网格排版不变。
- 检查点击整卡、滚动、左右展开、深浅色及菜单外点击／系统返回收起。
