# v1.2.0-test.11 · 卡片底框与鲜明配色

2026-09-28，版本码 124。本地实测包。

## 本次修改

按用户提供的旧版圆角卡片外观参考调整菜单，保留已经确认的整卡点击与紧凑排版。

1. 每张卡片保留独立实心底框、16 dp 圆角，增加 1 dp 细边框及轻阴影。关闭、普通执行动作和只读卡片使用浅色白底／深色灰底，与外层面板分开。
2. 开启直接沿用原开关绿色：浅色 `#34C759`、深色 `#30D158`；等待为鲜明蓝色，未知或离线为鲜明橙色，保留刷新／异常标记。
3. 不可操作的米家卡片仍按原规则禁用，但不再将整张卡片透明度降为 0.6，防止底框和颜色一起变淡。
4. 卡片标题、状态图标及 Surfing 数值、文案、进度条同步适配实色背景，深色模式也保持清晰文字。WebUI 布局预览同步底框及配色。

沿用 test.10 的整卡点击、五字标题空间、温湿度名称与数值同行、正常读数去除“云端上报”；图标读取与复制诊断、Surfing 显示条件、状态判断、命令、配置及 APK 签名保持兼容。

## 安装与实测

在 KernelSU 覆盖安装 `test_oppo_sidekey_v1.2.0-test.11.zip` 并重启，重新打开 WebUI 确认 test.11，再双击侧键查看实际菜单。

- 关闭与只读卡片应有清楚的圆角底框，浅色模式为白色，深色模式为深灰色。
- 手电筒、米家开关及 Surfing 在真实开启后使用鲜明绿色；等待和异常仍能区分，不显示为关闭。
- 检查 Surfing 开启后的标题、数值、说明与进度条在绿色背景上是否清楚。
- 检查五字标题、温湿度两行、滚动时卡片复用以及深浅色切换；独立按钮不恢复。

## 编译与验证边界

运行 `python build.py`，执行 JavaScript 语法、SF Symbols 资源、ARM64／Java／API 35 编译、DEX、APK 签名和 ZIP 内容核对。已有 AppCatalog 已过时 API 提示沿用，结果见构建日志；交付时核对签名证书与 test.10 相同。

按项目约定不运行自动测试、浏览器测试、联网测试或 ADB。配色及触控效果待用户真机验收，未推送、打标签或发布。
