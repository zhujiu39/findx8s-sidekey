## 本次修改

1. 取消 test.13 的标题居中，卡片标题和辅助文字恢复左对齐，移除右侧对称占位。
2. 顶部横条与原大块空白继续删除，面板顶部额外边距也归零，第一张卡片直接从顶部开始。
3. Surfing 统计改为名称与数值同行。小于 180 dp 时，原默认标签缩短为「↑速率」「↓速率」「↑流量」「↓流量」；自定义文字和隐藏项保留。300 dp 以下单列，宽栏两列。
4. 订阅保留名称、已用、总额、进度和更新时间，数值与单位紧邻，已用与总额各占紧凑一行；长文案或大字体自然换行，不截掉读数。
5. 收紧代理展开后的标题区域、统计行距、分隔和订阅间距。关闭时仍是原整卡入口，只有确认开启才显示详情。WebUI 布局预览同步。

配色、整卡点击、五字标题、温湿度同行、应用图标、数据接口及配置格式沿用。核心统计说明、错误、缓存、缺失提示、订阅更新时间和完整无障碍说明保留；不会把读取失败填成 0。

## 真机安装与验收

在 KernelSU 覆盖安装 test_oppo_sidekey_v1.2.0-test.14.zip 并重启，确认 WebUI 显示 test.14。

- 120 dp 窄栏查看卡片标题左对齐，顶部无横条和额外空白。
- 开启代理，检查上传／下载速率、累计流量同行，两个订阅的已用和总额数值完整，应用网格不再被大块统计区域挤走。
- 关闭代理或等待切换时不显示具体信息，整卡颜色与原规则一致。
- 查看自定义长文案、隐藏字段、大字体、多订阅、缺失／缓存／错误状态；长文本允许换行，单位和提示不被省略。
- 检查宽栏两列、深浅色、滚动复用、整卡操作及菜单外／返回收起。
