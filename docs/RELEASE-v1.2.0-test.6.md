# v1.2.0-test.6 · 快捷栏配置统一与深浅色背景

2026-09-28，版本码 119。本版统一 WebUI 四页的视觉样式，补齐快捷栏配置页。双击侧键弹出的原生快捷菜单外观与交互保留。

## 本版变化

- **浅色纯白，深色深底。** 去掉上一版装饰壁纸。设置页保留“浅色／深色／跟随系统”；背景、文字、卡片、导航和弹窗一起适配，已有外观偏好继续生效。
- **快捷栏配置页统一。** 顶部显示应用和快捷项数量及预览入口；下方提供应用、快捷操作、米家、Surfing 四类添加卡片，再按菜单内容、菜单布局组织编辑。
- **原有功能完整保留。** 应用多选、上下排序、移除、名称和动作参数、米家已有设备／场景／读数及自定义文案、Surfing 五类显示项与全部文案、左右方向、宽度、间距、中心位置均可继续配置。
- **编辑层级一致。** 项目点按展开；米家读数文案使用同一折叠布局；应用和动作选择面板统一字号、圆角和触控尺寸。新增 Surfing 后直接展开配置；有待配置项目时不再显示“还没有快捷项目”。
- **四页共用导航和保存条。** 页面切换保持同一视觉结构；存在配置修改时显示保存条。减少动态效果与系统偏好继续有效，SF Symbols 来源与资源不变。

米家添加入口选择已经保存的项目；新设备、动作或读数仍从米家页配置。界面数量与状态均读取现有数据，不填充演示内容。

## 原生菜单与兼容性

原生快捷菜单 Java、Android 界面资源、布局预览脚本、应用图标请求、Root 桥接、米家服务及 Surfing 后端不修改。APK 只提升版本信息，沿用原签名证书；双击弹出菜单仍独立响应 Android 系统的深浅色。配置格式不变，保留已有手势、应用、菜单布局与米家登录。

## 安装

在 KernelSU 中覆盖安装 `test_oppo_sidekey_v1.2.0-test.6.zip`，重启手机，然后关闭旧 WebUI 并重新打开。请确认页面版本为 test.6；无需卸载旧模块。

## 真机实测

1. 设置 → 外观：分别选择浅色和深色，再选跟随系统并切换手机主题；检查四页、应用选择、动作选择和米家详情的背景、文字及卡片。重新打开后确认选择保留。浅色页面背景应为纯白。
2. 快捷栏：确认旧应用与快捷项仍在，打开应用多选，检查名称与图标；试新增、排序、移除及保存。新建快捷操作时应显示编辑卡片而非空列表提示。
3. 米家和 Surfing：检查已有项目选择、读数文案、Surfing 显示项与自定义文案、恢复默认。未保存的菜单修改应显示保存条。
4. 菜单布局：展开后调整左右、宽度、间距、中心位置，打开布局预览，保存后双击侧键检查实际效果。
5. 双击弹出的原生菜单：核对原有外观、滚动、系统深浅色、小窗启动、开关、米家读数和 Surfing 状态；本版没有修改其 UI 实现。

## 构建与验证范围

使用 `python build.py`，执行 JavaScript 语法、SF Symbols 来源校验与转换、ARM64／Java／API 35 编译、DEX、APK 签名及安装包完整性检查。构建日志保留原有 AppCatalog 使用已过时 API 的编译提示。本版未运行自动测试、浏览器测试、联网测试或 ADB；真机视觉、触控和业务结果待用户确认。
