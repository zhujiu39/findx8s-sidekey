# 家庭式 WebUI 设计依据

2026-09-28，更新至 v1.2.0-test.9。手势、快捷栏配置、米家和设置四页采用同一视觉体系。浅色页面为纯白背景，深色页面使用深色背景；WebUI 和原生菜单使用紧凑同行开关，Surfing 关闭时隐藏详细信息。

## 官方参考

- [Apple 家庭 App 概览](https://www.apple.com/home-app/)：分类位于上方，场景与房间有明确层级，配件用卡片呈现。
- [iPhone 上的“家庭”介绍](https://support.apple.com/zh-cn/guide/iphone/iph22d98bbca/ios)：查看家庭、分类和房间之间的组织方式。
- [官方 iPhone 界面截图](https://help.apple.com/assets/68FABD5B6EF504342600E3E5/68FABD675A41CCC23909151C/zh_SG/8edc93a984ed37d6571bb268d2dda133.png)：观察壁纸、浮动底栏、分类胶囊、卡片状态和字号。
- [官方房间卡片截图](https://www.apple.com/v/home-app/j/images/overview/homeapp_endframe__fuk5y4isv3u6_large.jpg)：观察房间标题、横向与纵向卡片、图标和数值的层级。
- [HomeKit 人机界面指南](https://developer.apple.com/design/human-interface-guidelines/homekit/)：沿用家庭与房间层级，不重复创建用户已有的家庭组织。

官方截图仅用于设计研究，未进入模块或源码交付包。按用户要求移除 test.5 的装饰壁纸，改用深浅色纯色背景。功能图标继续使用用户提供的 SF Symbols，来源清单和许可说明保留。

## 在模块中的落实

| 界面 | 信息组织与交互 |
| --- | --- |
| 手势 | 顶部左标题、右开关；正常接管不重复写状态，连接和异常提示保留。短按、双击、长按各一张动作卡。点按进入详情面板，完成后回到首页保存。应用、米家、自定义命令等原有参数全部保留。 |
| 快捷栏配置 | 数量与预览概览 → 应用、快捷操作、米家、Surfing 添加入口 → 可展开项目和应用列表 → 菜单布局。排序、移除、名称、参数、读数文案、Surfing 显示项及布局参数保留。 |
| 原生快捷菜单 | 左侧标题、右侧开关；移除重复状态文字，以颜色及图标表示开关、等待和未知。Surfing 确认开启后才显示勾选内容，关闭时无占位；布局预览同步。 |
| 米家首页 | 家庭名称和切换入口 → 设备分类 → 手动场景 → 按房间分组的设备。搜索和房间筛选在设备区，有明确清除入口。 |
| 米家详情 | 设备名称和所属房间 → 最多四项实际读数摘要 → 读数卡配置 → 分组控制与设定。布尔属性状态用标题右侧颜色图标表达，点击行仍展开配置。全部可选读数仍在配置区可见，未因摘要上限删除。 |
| 米家管理 | 账号入口位于右上角；全部家庭的已存绑定进入“我的项目”；执行记录折叠展示。 |
| 设置 | 保留外观、按键时序、减少动态效果及日志工具；统一分组、留白和文字层级。 |

在线／离线是云端目录返回的连通状态，不代表开关已开启／关闭。首页采用紧凑设备行和详情入口，不常驻重复状态文字；离线样式与无障碍说明保留。详情布尔属性只依据已读回的布尔值着色，离线或无数据用未知图标，不模拟开关或温度。

分类由目录中的设备型号和名称匹配环境、照明、安防、电源，其余归入其他；这是界面查找辅助，不影响设备实际 MIOT 能力。读数、范围、单位和控制参数仍由原米家服务返回。

## 视觉与动效

- 浅色背景为纯白，深色背景为 `#141416`；正文、边框、卡片、控件和弹窗通过同一主题变量切换，不叠加壁纸。浅色以细边框区分卡片，深色以表面亮度区分层级。
- 手机设备采用单列紧凑行与独立房间标题，场景保留两列，桌面增加列数。长中文名称可换行，按钮点击区域至少 44 px。
- 主标题 34～36 px，分区 19～23 px，设备名称 15 px，状态 12～13 px；数值采用等宽数字。
- 页面切换约 280 ms，详情面板约 300 ms；系统减少动态效果和模块内对应设置均禁用动画。
- 保留浅色、深色与跟随系统，以及本机偏好记忆。跟随系统时实时响应系统主题变化，四页在存在未保存配置时显示保存条。

## 实现与边界

`home-interface` 皮肤覆盖全部四页，外观偏好脚本保持原有切换逻辑。应用列表插入后直接请求首批图标，后续使用观察器及滚动加载；优先使用 KernelSU 官方本机图标 URI，不支持或单项失败时使用受限 Root PNG。选择器的复制按钮提供逐应用诊断，保留包名、阶段与原因。原生菜单继续沿用 test.7 的开关卡片与 Surfing 显示条件，图标资源和签名证书沿用。

本版没有改 Root 命令桥接、米家服务、配置格式、手势识别、应用启动或 Surfing 后端。没有引入 HomeKit 通信协议；参考的是 Apple 家庭 App 的界面组织。
