# v1.2.0-test.5 · 家庭风格 WebUI

2026-09-28，版本码 118。本版参考 Apple 家庭 App 的界面组织，重做手势、米家、设置三页。**快捷栏编辑页、布局预览和手机侧原生快捷栏 UI 保持不变。**

## 本版变化

- 原创柔焦壁纸、半透明分类与导航、分组卡片、底部详情面板；保留 SF Symbols、浅色／深色／跟随系统以及减少动态效果。
- 手势首页改为三张动作卡片，直接展示已选动作。点按进入配置面板，保留应用选择、米家绑定、按键码、Shell 和执行入口。完成后仍需保存设置。
- 米家页按家庭、分类、场景和房间组织。新增环境／照明／安防／电源／其他分类，按房间筛选、名称搜索及清除筛选。
- 米家设备详情先展示实际读数摘要，再按需展开读数卡选择、文案编辑、控制属性和动作参数。所有设备能力保留；摘要最多四项，全部读数在配置区选择。
- 账号管理移到右上角；已存读数与动作位于“我的项目”，最近执行记录位于页面下方。
- 修整面板异步生命周期：关闭后旧设备请求不再覆盖新面板；读取失败有重试入口；绑定列表内容未变时不重复重建。
- 手势、米家和设置页面只在有未保存修改时显示保存条；快捷栏维持原保存条和交互。

在线并不等于开启。首页展示米家云端返回的在线／离线状态；设备详情注明读数来自云端最近上报，离线数据可能不是当前状态。没有模拟家庭、设备、温度或执行结果。

## 安装

在 KernelSU 覆盖安装 `test_oppo_sidekey_v1.2.0-test.5.zip` 并重启，再关闭旧 WebUI 并重新打开。保留原配置格式和 APK 签名，无需重建手势、快捷栏或米家绑定。

## 真机重点验收

1. 手势页：打开三张动作卡，切换动作、选择应用或米家绑定；完成后保存，再验证实际侧键动作。
2. 米家页：检查家庭切换、分类、房间、搜索与清除；查看已有手动场景和各房间设备。
3. 设备详情：检查实际读数、1～4 项读数卡、展开文案编辑、控制与设定、动作参数，以及已保存项目管理。
4. 读取设备过程中关闭面板，再打开其他设备；确认旧请求不会把面板内容替换回去。
5. 浅色、深色、减少动态效果，以及小屏幕／长设备名；检查底部导航和保存按钮不被系统区域遮挡。
6. 进入快捷栏确认编辑页、布局预览和实际侧键菜单仍与 test.4 一致。

## 构建与限制

运行 `python build.py`：JavaScript 语法、71 项 SF Symbols 来源、ARM64／Java／API 35 编译、D8、APK 签名及 ZIP 完整性检查；实际结果见同目录 `构建日志.txt`。

Java 编译仍提示 AppCatalog 使用已过时 API，该接口本轮未改；这项既有提示没有阻断编译、DEX 或签名。原生菜单的 DEX 和资源与 test.4 相同，仅版本清单及对应签名元数据改变。

按项目约定没有运行自动测试、浏览器测试、联网测试或 ADB。本版未进行真机视觉与触控验收，不能将编译通过视为手机验证通过。保留 test.4 的图标加载修复；本轮没有修改应用图标获取链路。

设计研究与功能对应关系见源码包中的 `docs/HOME-UI-DESIGN.md`。
